# Apresentação Online - Candidata Liliane Nicoletti

Projeto digital desenvolvido para a Candidata Liliane Nicoletti, permitindo que suas propostas sejam compartilhadas de maneira refinada e exclusiva. O foco é oferecer uma experiência otimizada para dispositivos móveis, garantindo acessibilidade e visual atraente em todas as plataformas.

## Passos para Acessar

1. Faça o clone do repositório:

    ```bash
    git clone https://github.com/JonatasVieiraa/LP-Liliane.git
    ```

2. Entre no diretório:

    ```bash
    cd LP-Liliane
    ```

3. Abra o arquivo `index.html` no navegador para ver a apresentação.

## Organização do Projeto

- **index.html**: Estrutura principal da apresentação.
- **styles.css**: Estilo visual para um layout refinado e responsivo.
- **script.js**: Funcionalidades adicionais e interações.
